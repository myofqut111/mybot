# 自主探索 命令手册（mybot_explore）

> 适用版本：`mybot_explore 0.1.0`（仓库 `457fd49`）
> 机器上装的是改名前的包名，**执行命令时把 `mybot_` 换成 `fishbot_`**
> 最后更新：2026-11-13

---

## 1. 一句话

独立功能包，和巡检并列：**不改任何现有包**，只订阅地图和激光、调用 Nav2 的
`navigate_to_pose`，自己决定"下一个该去哪"。

- 巡检 = 按清单跑（点位是录好的）
- 探索 = 自己找活干（点位是自己算出来的）

---

## 2. 前置条件（三件套，缺一不可）

| 条件 | 怎么确认 | 不满足的后果 |
|---|---|---|
| 有地图 | `ros2 topic hz /map` 有输出，或直接给 `map_yaml` | `map_ready: false`，停在 idle |
| 车有定位 | `ros2 run tf2_ros tf2_echo map base_link` | 发不出目标，或全判失败 |
| 激光在流 | `ros2 topic hz /scan` | 能走但擦图不生效，走一步就"到头了" |

> **定位这一条最容易漏**。车没定位就发目标，nav2 一直回失败，探索会以为
> "这个点不可达"，把好好的前沿点拉黑——所以要等 RViz 里车出现在地图上再启动。

---

## 3. 启动方式（三档，一层比一层主动）

```bash
# ① 看图模式（默认）：只发红球，车一动不动
ros2 run mybot_explore explore_node

# ② 看图 + 指定地图文件（不必等 Nav2，开机就能算）
ros2 run mybot_explore explore_node --ros-args \
    -p map_yaml:=/home/my/maps/map_v2.yaml

# ③ 开车模式，但要按一下才走
ros2 run mybot_explore explore_node --ros-args -p drive:=true
ros2 service call /explore/start std_srvs/srv/Trigger

# ④ 开车模式，起来就自己跑
ros2 run mybot_explore explore_node --ros-args -p drive:=true -p autostart:=true

# 用 launch（带 yaml 参数文件）
ros2 launch mybot_explore explore.launch.py drive:=true autostart:=true

# 停
ros2 service call /explore/stop std_srvs/srv/Trigger
```

> `map_yaml` 可以不给：不给就订阅 `/map`（`map_server` 或 `slam_toolbox` 发的）。
> 给了就直接读 pgm，**不用等 Nav2**，适合离线看图。

## 4. 参数

### 4.1 看图（前沿怎么算）

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `map_topic` | `/map` | 用别的图话题时 |
| `base_frame` | `base_link` | 车机座架不是 base_link 时（常见 `base_footprint`） |
| `period_s` | `1.0` | 想算得更勤（0.5）或更省 CPU（2.0） |
| `min_size` | `4` | 碎点太多 → 调大到 8~12；一个都找不到 → 调到 2 |
| `unknown_radius_m` | `1.0` | "去了能看见多少未知"的统计半径 |
| `max_candidates` | `20` | 一次最多给几个候选 |
| `min_separation_m` | `1.0` | 候选挤在一起 → 调大；想精细选点 → 调小到 0.5 |
| `goal_clearance_m` | `0.35` | 目标老被 nav2 拒"在障碍里" → 调到 0.5（车大就更大） |
| `w_distance` | `0.6` | 想让车优先去近的 → 调大 |
| `w_gain` | `0.4` | 想让车优先去"能看见一大片"的 → 调大 |

### 4.2 擦图（让未知边界往后退）

静态地图不会自己更新，未知边界永远不动，车走到边上就"到头了"。擦图用激光把
光束经过的未知格改成空闲，边界跟着车后退，才能一层层往里探。

| 参数 | 默认 | 说明 |
|---|---|---|
| `carve_enabled` | `true` | 关掉就退化成"只走到已知边界为止" |
| `carve_max_range_m` | `4.0` | 只信这么远以内的光束（远处噪声大） |
| `carve_robot_radius_m` | `0.25` | 车身这一圈直接擦成空闲 |
| `carve_period_s` | `0.5` | 最快多久擦一次 |

### 4.3 开车（怎么走、什么时候放弃）

| 参数 | 默认 | 说明 |
|---|---|---|
| `drive` | `false` | **true 才会真的发导航目标** |
| `autostart` | `false` | true 起来就跑，false 等 `/explore/start` |
| `nav_action` | `navigate_to_pose` | 换导航 action 时改 |
| `visited_radius_m` | `1.2` | 走过一个点，周围这么大算"看过"（不重复去） |
| `min_goal_distance_m` | `0.8` | 太近的点不去，免得原地打转 |
| `max_goal_distance_m` | `15.0` | 太远的点不去（走一半没电更糟） |
| `settle_s` | `1.0` | 到点后等多久再重算前沿（等激光扫一圈） |

### 4.4 超时与收工

| 参数 | 默认 | 说明 |
|---|---|---|
| `nav_timeout_s` | `90.0` | 单个目标最多给这么久，超时算失败 |
| `stuck_window_s` | `10.0` | 这么久没挪窝算卡住 |
| `stuck_move_m` | `0.05` | "挪窝"的门槛，10 秒内移动不到 5 cm 就算卡住 |
| `progress_epsilon_m` | `0.15` | 判定"在进步"的最小距离 |
| `max_consecutive_failures` | `3` | 连续失败这么多次整场收工 |
| `max_duration_s` | `1200.0` | 整场最多 20 分钟 |
| `return_home` | `true` | 探完回起点 |

## 5. 话题与服务

| 名称 | 类型 | 方向 | 内容 |
|---|---|---|---|
| `/map` | `nav_msgs/OccupancyGrid` | 订阅 | 地图（TRANSIENT_LOCAL） |
| `/scan` | `sensor_msgs/LaserScan` | 订阅 | 激光（BEST_EFFORT 也能收） |
| `/explore/frontiers` | `visualization_msgs/MarkerArray` | 发布 | 候选前沿点（分数越高越红） |
| `/explore/candidates` | `geometry_msgs/PoseArray` | 发布 | 同上，给工具用 |
| `/explore/blacklist` | `visualization_msgs/MarkerArray` | 发布 | 失败过的点（灰块） |
| `/explore/status` | `std_msgs/String` | 发布 | 状态 JSON（见下） |
| `/explore/start` | `std_srvs/Trigger` | 服务 | 开始探索 |
| `/explore/stop` | `std_srvs/Trigger` | 服务 | 中止并回起点 |

---

## 6. `/explore/status` 字段

```bash
ros2 topic echo /explore/status
```

| 字段 | 含义 |
|---|---|
| `state` | `idle` / `select` / `navigate` / `settle` / `return_home` / `done` |
| `done_reason` | 收工原因：`no_frontier` / `returned_home` / `max_duration` / `failed` |
| `goals` / `succeeded` / `failed` | 一共发了几个目标、成功几个、失败几个 |
| `blacklist` | 已拉黑的点数 |
| `consecutive_failures` | 连续失败次数（到 3 就收工） |
| `distance_m` | 走了多远 |
| `map_ready` | **图到了没有** |
| `scan_ready` | **激光到了没有** |
| `carved_free` / `carved_occupied` | 擦图累计计数（一直 0 = 激光没进来） |

一眼判读：

| 现象 | 结论 |
|---|---|
| `map_ready: false` | 图没来 → 查 `/map`、查 `map_server` 的 `yaml_filename` |
| `scan_ready: false` | 激光没来 → 查 `/scan`、查 QoS |
| `carved_free` 一直是 0 | 激光来了但没进 `_carve()` → 看 `carve_enabled` |
| `blacklist` 一直涨 | 目标点选在到不了的地方 → 调大 `goal_clearance_m` |

## 7. 验证三步

### 第 1 步：离线看图（不用 ROS，30 秒）

```bash
cd ~/fishbot_full_ws
python3 src/fishbot_explore/tools/explore_offline.py \
    ~/maps/map_v2.yaml --pose 8.19 3.17 --min-size 8 --out /tmp/f1.png
```

拷出来看图：灰=未知、白=空闲、黑=墙、红圈=候选、绿点=车、浅蓝=已走过。

**通过标准**：红圈压在"白/灰交界"上，10~30 个，不是满屏乱点。

### 第 2 步：mock（5 分钟，不用真车）

```bash
bash tools/run_mock_explore.sh 120     # 或 VM 上的 /tmp/run_mock_explore.sh
```

**通过标准**：

```
前沿 3 个，最佳 (4.98,4.62)      ← 门口
前沿 1 个，最佳 (6.43,7.33)      ← 走进未知区了
前沿 2 个，最佳 (7.98,8.43)
没有前沿：要么地图还没建，要么已经探完
去 (home) (2.00,2.00)
```

并且"未知面积"从 500 多一路掉到个位数。

### 第 3 步：真机（先看图，再开车）

**3.1 只算不动**（最重要，别跳过）

```bash
ros2 run fishbot_explore explore_node
```

RViz 加两个 Display：`MarkerArray → /explore/frontiers`、`PoseArray → /explore/candidates`。

通过标准：红球出现在你没去过的地方；车挪一下红球跟着重算；终端 1 Hz 刷
`前沿 N 个，最佳 (x,y)`。

**3.2 让它走一个**（手放急停上）

```bash
ros2 run fishbot_explore explore_node --ros-args -p drive:=true -p autostart:=true
```

看三件事：车朝红球走 → 到点停 1 秒 → 红球往后缩（擦图生效）。

## 8. 正常日志长什么样

```
[INFO] 已直读地图 /home/my/maps/map_v2.yaml：242x288 @0.05m
[INFO] 前沿 12 个，最佳 (3.33, 0.00) 分数 1.00，未知面积 1228 格
[INFO] 去 (3.33, 0.00) 分数 1.00
[INFO] 导航结束：状态 4
[INFO] 前沿 5 个，最佳 (5.83, 0.23) 分数 0.40，未知面积 59 格
[INFO] 没有前沿：要么地图还没建，要么已经探完
[INFO] 去 (home) (2.00, 2.00) 分数 0.00
[INFO] 导航结束：状态 4
```

`状态 4` 是 nav2 的 `STATUS_SUCCEEDED`。**收尾一定要看到"导航结束"**，否则可能
还在跑。

## 9. 故障对照表

| 现象 | 根因 | 处理 |
|---|---|---|
| 一直 `前沿 0 个` + `map_ready: true` | 这张图没有灰区（已被探完），或读错了图 | 换有未知区的地图；`ros2 param get /map_server yaml_filename` 核对 |
| `map_ready: false` | 没图 | 起 Nav2 或给 `map_yaml` |
| `carved_free` 一直 0 | `/scan` 没进来（QoS 最常见） | `ros2 topic hz /scan`；订阅端已用 `qos_profile_sensor_data`，还收不到就是发布端没发 |
| 目标全被拒 `在障碍里` | 前沿贴边，落在膨胀区 | 调大 `goal_clearance_m`（0.35 → 0.5） |
| 车来回转圈不去新地方 | 拉黑没生效 / 覆盖层没画 | 看 `blacklist` 和 `visited` 是否在涨 |
| 走了几步就"没有前沿" | 擦图关着 | `carve_enabled: true` |
| 一直 `select` 不发目标 | 目标都太近（`min_goal_distance_m`）或太远（`max_goal_distance_m`） | 调这两个阈值 |
| 起来 10 秒还没动 | 三件套没齐 | 看 `/explore/status` 的 `map_ready` / `scan_ready` |

## 10. 收工条件与安全

自动停的四种情况：

| 什么时候 | `done_reason` |
|---|---|
| 没有前沿了 | `no_frontier` |
| 连续失败 3 次 | `failed` |
| 满 20 分钟 | `max_duration` |
| 探完回起点成功 | `returned_home` |

**安全须知**：

1. 第一次上真机**只跑看图模式**（不加 `drive:=true`）
2. 开车必须有人手放急停
3. 探索和巡检**不要同时跑**（两个都发 `navigate_to_pose`，会互相抢目标）
4. 看门狗（`fishbot_safety`）可以同时开，它只管"车在动但没人指挥"的情况

## 11. 和巡检的关系

| | 巡检 `mybot_patrol_v2` | 探索 `mybot_explore` |
|---|---|---|
| 点位从哪来 | 录点（人走到位置记下来） | 算法算（前沿检测） |
| 要不要地图 | 要（导航用） | 要（找未知区用） |
| 结束条件 | 点位跑完 | 没有未知区了 |
| 输出 | 报告（每点检测结果） | 一张被探完的地图 |

两者**并列**，不互相调用。想让"巡检到某点后顺便探一圈"，再做成服务调用，现在不做。

## 12. 相关文件

| 文件 | 作用 |
|---|---|
| `mybot_explore/frontier.py` | 前沿检测、聚类、打分、离墙校正 |
| `mybot_explore/visited.py` | 覆盖层（走过的记下来） |
| `mybot_explore/explorer.py` | 状态机（select → navigate → settle） |
| `mybot_explore/carve.py` | 擦图（激光把未知擦成空闲） |
| `mybot_explore/pgm.py` | 读 pgm/yaml（trinary 还原未知） |
| `mybot_explore/node.py` | ROS 节点：订阅、发 marker、调 Action |
| `mybot_explore/tools/explore_offline.py` | 离线看图（不出 ROS 也能跑） |
| `mybot_explore/tools/make_partial_map.py` | 造"只探了一半"的 mock 地图 |
