# 定位 / 建图 / 检测 分层改造骨架 v2（2026-11-27 用户审定）

> 本文是双方确认后的实施骨架。后续改动以此为准；与旧方案冲突处，以本文为准。

## 0. 为什么改

现状是一条链、三个弱点、一个都没设防：

```
轮子编码器 → /odom → EKF → base_link ──┐
                                       ├→ slam_toolbox → 地图
激光 → ICP → 速度观测（新加）──────────┘
                ↓
        打滑检测（0.4 s 窗口，事后）→ 门控 / 恢复（更晚）
```

1. 位姿只有一个会撒谎的源（轮子）。打滑时它立刻错，检测最快 0.4~1 s 才确认，保护永远迟到。
2. 建图不设防：有帧就写，写的时候没人问“当前位姿可信吗”。
3. 检测被拿来当刹车：用不可信的激光速度否决可信的轮速，走廊里必然误判 —— 实测 `/scan` 5028 帧只写进去 2259 帧（丢 53.7%）。
4. 没有可复现的判据：每次现场试错，改了什么、好没好全靠眼睛。

## 1. 五层结构

| 层 | 职责 | 现状 | 缺什么 |
|---|---|---|---|
| L0 数据质量 | 时间戳、频率、断流、IMU 安装偏差 | 有（时间戳回退、断流门、倾角基准） | QoS / 丢包统计 |
| L1 位姿 | 轮式 + 陀螺 + 激光速度，**带权重与退化处理** | 只接了固定协方差的 vx/wz | **退化轴识别**、协方差标定、EKF 拒收统计 |
| L2 位姿可信状态 | **多维状态量**，见 §2 | S0~S4 骨架有 | 与 L1 观测质量联动 |
| L3 建图门控 | 暂停/恢复，**只消费 L2 状态** | 有但判据错（门控里重算轮速-激光比较） | 质量闸门、启动等待、暂停占比统计 |
| L4 恢复 | 按类型分流、两次上限、冷却、S4 安全停车 | 基本齐 | 真机验证（最后接） |
| L5 度量与回放台 | 固定包 + 固定 SLAM 参数，比较改造前后相对变化 | 有脚本未成体系 | 图质量报告、分段标注、pass 表 |

**结构上真正要改的一件事**：把“写不写图”从“检测到打滑”改成“**位姿是否可信**”。S1（疑似）就该停写，恢复要等位姿真的好了，而不是等动作做完。

## 2. 位姿可信 = 多维状态，不是一个布尔量

至少分别维护，并发布到 `/slip/state`：

- `loc_valid`：定位观测（融合位姿）是否有效；
- `wheel_trust`：轮式里程是否可信（good / degraded / frozen）；
- `laser_degraded`：激光是否处于退化（走廊/大平面/玻璃）；
- `pose_jump`：融合位姿是否发生异常跳变；
- `map_allowed`：当前是否允许写持久地图（由以上几项合成）。

建图门控**只消费这些状态**，不得在门控里再比较一次轮速与激光速度。

## 3. S1 的三路判断（用户修正 1）

“观测不一致”只能说明至少一路有问题，不能直接证明轮子在撒谎：

| 情形 | 动作 |
|---|---|
| 激光质量差 | 拒绝激光观测，保留正常轮式定位，记录退化 |
| 激光质量高且与轮速持续矛盾 | 轮式 odom 降权或冻结，由激光维持相对定位 |
| 无法判断哪一路异常 | 限速 + 暂停持久建图，**不贸然切换定位源** |

这样才不会再出现“走廊里的坏激光否决正常轮速”。

## 4. 阶段与门槛（相对基线，不做通用指标）

顺序：**A 固定基线与真值参考 → B 激光质量与按轴融合 → C 独立位姿可信状态驱动建图 → D 真机灰度 → 最后接恢复动作**。

| 阶段 | 做什么 | 判定方式 |
|---|---|---|
| A 基线 | 固定一条路线、一套 SLAM 参数；scan_match **只旁路记录**（原始 ICP、轮式 odom、质量），关掉它对 EKF 与门控的控制作用 | 同一包改造前后对比 |
| B 质量与融合 | 质量档 + 退化轴识别；EKF 按轴加权；三轨迹对比 | 正常段被拉偏、打滑段前冲改善 |
| C 门控闭环 | 多维位姿状态驱动建图；S1 即停写；恢复需位姿可信；指标上报 | 四个指标（见下） |
| D 真机灰度 | 日志 → EKF → 门控三段；每次跑完自动出图质量报告 | 现场报告 |

### 指标（用户修正 3）

**禁止**把“丢帧率 < 5%”之类写成通用硬门槛——真实持续打滑或激光退化时，多拒绝一些地图帧是正确行为。改为：

1. 正常段**误暂停率**；
2. 异常段**应暂停而未暂停**的比例；
3. 正常建图**覆盖率损失**；
4. 恢复后**重复墙 / 地图跳变 / 错误写入**次数。

所有阈值以“同一 rosbag + 同一套 SLAM 参数下改造前后的相对变化”表述；“已知率 >35%、孤立障碍 <10%”只作为当前路线与测试包的**临时基线**，不得写成所有环境的合格标准。

## 5. 真值参考的约束（关键）

回放里的 **ICP 积分轨迹不能直接当真值**，否则只是把轮式误差换成 ICP 误差。要求：

- 选择有明确起终点、可测量参照物（地面标线、墙距）的测试路线；
- 或人工标注“正常 / 打滑 / 退化”片段（`labels.json`：`[{"t0":…,"t1":…,"kind":"normal|slip|degraded"}]`）；
- 每个阶段结论必须落到这份标注上。

## 6. 兜底原则

- 每层独立开关、默认关，出问题一键回原系统；
- 判据以“回放包 → 指标”为准，不再靠现场感觉；
- 每次交付只报“通过了哪几条、没过哪几条”，不报“我做了什么”。

## 7. 一句话原则

**检测负责解释发生了什么；定位负责尽量不算错；建图负责不确定时不留下永久错误；回放指标负责证明确实改善。**
